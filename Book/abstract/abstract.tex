\chapter*{Abstract}
\label{cha:abstract}

\addcontentsline{toc}{chapter}{Abstract}

This work integrates SCADA systems and historical databases into an
industrial monitoring network designed to support decisions through LLMs.
The historical database that collects a plant's electrical consumption data
is deployed on the N3uron platform, and supervision is handled through a
SCADA interface built with WebVision. The MCP module connects that platform
to an LLM agent deployed in AnythingLLM, enabling the historical data to be
queried in natural language. The system is validated by comparing different
models and providers under the same prompts, laying the foundations for an
intelligent energy management environment.
